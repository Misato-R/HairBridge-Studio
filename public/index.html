粗模生成与拆分任务

  1. 未登录？点「打开 Tripo Studio」登录自己的账号。若 agent 使用另一个浏览器，请在它打开的页面登录。
  2. 点「复制给 agent」，把任务粘贴到当前 Codex 对话。
  3. agent 用四视图生成一批候选，从同一个候选回填整头粗模、无发头模和独立头发。
  4. 在「粗模与拆分」页叠加审核。确认头模和头发后进入导线生成。
