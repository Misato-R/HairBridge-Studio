# Sources and reused material

- **HairDeck** — <https://github.com/hyz317/HairDeck>. The model and its Python environment are separately installed and are not redistributed. HairDeck tangent/frame mathematics reused by the earlier bridge remains credited in `addon/hairbridge_studio/hairdeck_bridge/frames.py`; its Apache 2.0 license is retained alongside it. Check upstream terms for the model and dependencies when installing them.
- **Earlier IIS HairDeck JSON Bridge** — reused from the user's existing `assignment/A2_Hair_Bridge/addon` source. Its curve fitting, coordinate mapping, SHP profile mapping and tip controls are retained. New integration code wraps it rather than claiming those components were created afresh in this stage.
- **Three.js** — <https://github.com/mrdoob/three.js>. MIT-licensed `three.module.js`, `OrbitControls.js`, `GLTFLoader.js` and `BufferGeometryUtils.js` are included in `public/vendor/`, together with `THREE-LICENSE.txt`. These files came from the locally installed Charakuru distribution's third-party vendor folder; no Charakuru application modules are included.
- **Charakuru** — <https://github.com/nanocle/Charakuru>. Reference for persistent local projects, staged visual review and browser-and-agent handoffs. Its application code, skills, assets and archive format are not redistributed here.
- **Stylized Hair PRO** — Dean Zarkov's separately installed Blender add-on, used for curve-driven geometry and refinement. The inspected local installation is version 4.3.1. [Author's product page](https://deanzarkov.gumroad.com/l/stylized_hair_pro). This public repository does not bundle SHP. The installed `blender_manifest.toml`, `README.txt` and `LICENSE.txt` identify MIT licensing, copyright 2026 Dean Zarkov. A separately prepared local teacher attachment retains those files unchanged. Its assessment-only request is the student's intended use, not a claim that the author's MIT license prohibits redistribution or commercial use. See [teacher attachment instructions](docs/teacher-verification.zh-CN.md).
- **Surface Hair Curve Tool** — version 0.1.0 authored by LU WENXUAN with Codex assistance. The source is included in `addon/surface_hair_curve_tool/` and a separate installer in `installers/`. Its two node-preset files were copied from the author's working installation; they reuse Blender hair node assets, which are not claimed as newly authored algorithms. The plugin remains separately enabled in Blender, rather than embedded inside HairBridge. It is not an independently published third-party product citation.
- **HairMesh** — [riel-gab/hairmesh repository](https://github.com/riel-gab/hairmesh), [release 1.1.1 used in the experiment](https://github.com/riel-gab/hairmesh/releases/tag/v1.1.1). Used in the earlier Rain experiment to test importing, editing and exporting guide curves before returning them to SHP. See the [validation record](docs/validation.md). It is not a runtime dependency of the current workspace and is not bundled.
- **Hair Curve Toolkit** — version 0.24.18, credited locally to bilibili晴天雨. The author privately supplied the user's copy; no public installer link was supplied. Author's demonstration, linked by the student: [Blender 曲线毛发插件功能介绍与演示](https://www.bilibili.com/video/BV1rqpe6sEVU/). Used in the earlier fixed-guide cross-section comparison, not as a runtime dependency of this workspace. The add-on and video files are not bundled; the public video is an operation reference, while the experiment record identifies the version actually used.
- **Tripo Studio / Smart Mesh P2.0** — external model-generation service operated through the user's signed-in Studio session and agent task handoffs. [P Series documentation](https://www.tripo3d.ai/product-doc/ai-3d-models/p-series-smart-mesh). Its [segmentation documentation](https://www.tripo3d.ai/product-doc/module-post-processing/segmentation) also informs the project's inspection rationale. Individual experiments distinguish Tripo segmentation from our own connected-component extraction and coordinate checks; service documentation is not evidence of this project's output quality.
- **Rain example** — the public `examples/rain-study/` includes one initial render, four AI-assisted reference views and derived Tripo/guide data from the recorded experiment. Original character: [Blender Studio Rain v3](https://studio.blender.org/characters/rain/v3/), CC-BY. Required credit: **Rain Rig (CC) Blender Foundation | studio.blender.org**. The study README identifies derivatives and limitations; its manifest records exact file hashes. The original rig is not bundled.

The newly authored project code has no general reuse license assigned. Public assessment access does not replace a license grant. Upstream licenses and asset-specific attribution continue to apply; no MIT license is asserted for the entire project.
